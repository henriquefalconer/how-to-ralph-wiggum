Set It Building, It Wants Two Things

04

Each pass grabs the next unfinished piece and makes it real. For that it needs to know what to build — and what good looks like.

THE LIST

Everything the product should do

Broken into pieces, each small enough to finish in one sitting, each written plainly enough that you can tell whether it is done.

It is also the scoreboard: every finished piece is marked off, so at any moment the state of the job is a count, not an opinion.

THE PLAN

How it should all hang together

The shape of the thing being built: how it looks, how the parts relate, what the standards are, and what order things should happen in.

Without it, a worker with no memory would invent a slightly different product on every pass. This is what keeps a hundred passes coherent.
