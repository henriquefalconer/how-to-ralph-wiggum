INSPECT MODE

Using Inspect Mode to Clone a Product

09

Told to look instead of build, Ralph works through an existing product one page at a time. Same loop, same short passes — but what it writes down is the specs and the plan. The looking is the work.

STEP 1

Read

Everything the product says about itself

→ its own documentation

→ how it explains its parts

→ what it tells developers

STEP 2

Map

Every place you can get to

→ the full list of pages

→ how they connect

→ what is left to visit

STEP 3

Open

One page, properly, per pass

→ click it, type in it, submit it

→ capture what it looks like

→ write down how it behaves

STEP 4

Settle

Turn all of it into the specs and the plan

→ the specs

→ the plan, in build order

→ ready to hand to build mode
